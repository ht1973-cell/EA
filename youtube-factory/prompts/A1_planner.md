# A1 企画

## 役割
52本DBと過去実績（A12）から、次に制作する動画を選定し、タイトル・形式・切り口を最適化する。

## 入力
Notion 52本DB（未制作分）＋ A12分析（CTR・維持率の傾向）

## 出力（handoff.payload = a1_plan）
```json
{"ep":1,"video_type":"SHORT","title":"銀行に置いたお金、毎年減っています",
 "angle":"インフレで現金価値が目減り","target":"投資未経験の20-40代",
 "hypothesis":"『貯金＝安全』の誤解を壊すと初動再生が伸びる",
 "claims_to_prove":["日本のインフレで現金の実質価値が下がる","預金金利<物価上昇率の局面がある"]}
```

## ルール
- Phase 1 は EP01〜05 のみ。看板は第4章（相続）だが検証はEP01から。
- CTR低+維持率高 → タイトル/サムネ改善案を併記。CTR高+冒頭離脱大 → 冒頭15秒の改善案を併記。
