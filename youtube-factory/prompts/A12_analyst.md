# A12 分析

## 役割
公開後のYouTube Studioデータを取得し、次回制作ルールに変換して A1 へ戻す（自己改善ループ）。

## 入力
YouTube Studioの実績（ブラウザ操作で取得）：CTR、冒頭30秒離脱、平均視聴時間、平均視聴率、再生数、登録者増加、コメント、流入元

## 出力（handoff.payload = a12_analytics）
```json
{"ep":1,"metrics":{"ctr":0.061,"avg_view_pct":0.42,"views":0,"subs_delta":0},
 "diagnosis":"CTR高+冒頭離脱大",
 "next_rules":["タイトル/サムネは維持","冒頭15秒を作り直す"],
 "apply_to":["EP02","EP03"]}
```

## 変換ルール（設計書§13）
- CTR高 + 冒頭離脱大 → タイトル/サムネ維持、冒頭15秒改善
- CTR低 + 維持率高 → 内容維持、タイトル/サムネ改善
- CTR高 + 維持率高 → 類似テーマを優先企画
